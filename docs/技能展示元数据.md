# 技能展示元数据

Platform 将技能身份、界面文案与内容版本分开处理。技能中心、Agent 私有技能和连接器技能共用展示解析规则。目录与原始声明不因界面语言变化而改写。

## 推荐写法

`gtjaqh-flow/SKILL.md` 示例（版本仅作示例，实际值由技能作者维护）：

```yaml
---
name: gtjaqh-flow
displayName: 国泰君安期货工作流
description: 用于国泰君安期货内嵌网页中的流程查找、填写、提交、审批及流程记录读取。
metadata:
  version: "1.0.0"
  revision: "2026-09-18-r18"
  i18n:
    zh-CN:
      displayName: 国泰君安期货工作流
    en:
      displayName: GTJA Futures Workflow
      description: Find, fill, submit, and approve workflows in embedded web pages.
---

# 国泰君安期货工作流

技能操作说明……
```

新技能建议 `name` 与目录名一致。运行时 ID（API `key`）仍来自目录，部分 ZIP 导入入口优先使用 frontmatter `key`，其次使用 `name` 推导 ID；不要通过修改 `name` 翻译技能。目录 key 与显式 `name` 不一致时返回 `skill_name_key_mismatch` warning，加载日志也会提示；仍可加载、使用，不自动重命名。

顶层 `displayName`、兼容的 `metadata.displayName`、`metadata.version`、`metadata.revision` 均为可选字符串。非空顶层 `displayName` 优先，空白或缺失时回退 `metadata.displayName`；两者不同产生 `skill_display_name_conflict` warning，不阻断加载。i18n 仍优先覆盖当前语言文案。版本建议使用带引号的语义化版本，但不强制迁移旧版本格式。`description` 仍是默认描述；翻译描述只用于展示，模型读取的原始技能内容保持不变。这些展示扩展是 Platform 约定，其他消费端不一定支持。

## 语言选择与回退

HTTP 复用现有语言解析：URL `locale`、`X-Locale`、`Accept-Language` 以及平台默认语言。WebSocket 使用连接语言；客户端发送 `/api/locale` 并等待成功响应后，再请求 `/api/skills` 或 `/api/agent`。当前网络层支持的语言范围沿用现有全局 i18n 契约，本功能不扩大全局支持语言。

名称按当前完整语言标签、基础语言、默认 `displayName`、既有 `name`、`key` 的顺序回退。描述独立按完整语言、基础语言、默认 `description` 回退。空白值视为缺失。`en-US` 可以回退 `en`；`zh-TW` 不自动使用 `zh-CN`。语言标签按大小写不敏感匹配。

平台按每次请求生成响应副本，不修改共享 catalog，不将某个请求的翻译缓存为全局名称。翻译表不出现在公开技能对象中；管理端打开、下载的原始 SKILL.md 仍完整保留作者内容。

客户端应优先展示 `displayName`，旧服务缺少该字段时回退 `name/key`；语言切换后重新请求目录和当前详情并刷新本地缓存。置顶、选择、挂载与历史引用始终使用 `key`。Platform 提供服务端解析；相邻 Desktop 仓库的原生技能市场已接入请求语言、已安装技能元数据及语言切换刷新。其他独立客户端仍需遵循上述请求与刷新约定。

## 版本与修订号

解析顺序保持兼容：非空顶层 `version` 优先，其次 `metadata.version`，都没有则未声明。新技能推荐只写 `metadata.version`。

两处版本不同会产生 `skill_version_conflict` warning，但不阻止技能使用。公共响应的 `version` 与兼容保留的 `meta.metadata.version` 使用统一解析结果。原文件不自动改写。

`revision` 是独立修订标记，不补位版本，不用于市场升级比较。不从目录、文件时间、Git、市场包版本或安装动作生成技能版本。

技能包版本与子技能版本保持独立。包导入响应和包列表中的子技能 `diagnostics` 可报告 `missing_skill_version` 或 `skill_package_version_mismatch`；诊断比较包内声明快照与当前安装内容，不阻断旧包安装，不修改 SKILL.md，也不写入包状态文件。

## API

`/api/skills`、管理端技能列表/详情/修改响应、Agent 详情技能项、管理端私有技能项、连接器技能列表/详情名称字段统一为 `key` 与必返 `displayName`，不再返回 `name`。未声明显示名称时回退到 SKILL.md 的 `name`，最终回退 `key`；版本与修订号仍为可选。`description` 返回当前请求语言对应的描述；不返回 `i18n` 或内部翻译数据。

例如英文请求的技能项：

```json
{
  "key": "gtjaqh-flow",
  "displayName": "GTJA Futures Workflow",
  "description": "Find, fill, submit, and approve workflows in embedded web pages.",
  "version": "1.0.0",
  "revision": "2026-09-18-r18",
  "configured": false
}
```

`/api/skills` 的全局目录、顶层 `pinned`、可选 `agentKey` 与 `configured` 行为不变。仅已声明的版本、修订号被返回，不生成占位版本。

## 校验与兼容

管理端和技能候选验证对无效展示字段、无效语言标签、重复语言及版本冲突报告 warning；无效翻译字段回退到其他可用文案，不使技能整体失效。既有技能无需新增字段即可继续运行。搜索仍包含原始技能内容，因此可以匹配元数据中的名称和翻译。

本改动不迁移部署目录中的技能、不更新作者版本、不改连接器或技能包的发布版本，也不扩展工具执行权限。新增技能可直接采用本文模板；现有技能可逐个补齐 metadata。
