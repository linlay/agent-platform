# 知识库中心（KBases Center）

知识库中心管理部署级独立知识库，不要求创建 Agent。WebClient 从设置菜单进入 `/kbases`，提供新建、列表筛选、详情、编辑名称与描述、删除、手动更新索引、文档浏览和全文召回测试。

## 存储和职责

目录固定从 `AP_RUNTIME_DIR` 派生为 `kbases-center`，不增加环境变量或 YAML paths 配置。当前 zenmind-env 部署为 `/Users/linlay/Project/zenmind/zenmind-env/kbases-center`。

```text
kbases-center/
  <随机稳定ID>/
    library.json        # 名称、描述、canonical 源目录、毫秒时间戳、索引状态
    index.sqlite        # KBX 管理的知识包数据库及同目录配套资源
```

源目录是 Platform 所在机器的已有绝对目录，创建时解析真实路径；创建后固定，换源时新建知识库。它不能包含中心目录或位于中心目录内。删除只移除中心中该 ID 的定义和 KBX 数据，不删除原始源目录。既有 `kbase/` Agent capability 存储不迁移、不覆盖。

`internal/kbasescenter` 负责定义持久化、路径校验、CRUD 和任务状态；`internal/kbx.CenterEngine` 调用受管 KBX；App 装配，Server 仅提供 HTTP 映射。模型配置由 Platform 生成部署级快照，不继承用户目录中的 KBX 配置。

## 索引与召回

新建后是 `unindexed`，手动更新后进入 `indexing`。初次调用 `collection add --name workspace`，后续用 `update -c workspace --no-commands`。注册成功但初次扫描中断时，重试先通过结构化集合目录判断是否已经注册。CLI 非成功退出或摘要不完整均进入 `error`；成功进入 `ready`。HTTP 请求结束不取消任务；Platform 停机取消任务，重启后的遗留 `indexing` 显示为中断，需要手动重试。每库同一时刻仅一个更新任务，更新期间拒绝编辑与删除。任务上限 30 分钟。

未配置向量时使用 `search --agent --full`，配置向量后使用混合召回，返回 KBX chunk、原文、来源、行号和相关性分数，最多 50 条。文件浏览消费 `ls --agent`，原文预览读取前 200 行并展示截断提示。没有命中以空结果呈现；KBX 不可用、索引失败和不完整结果不会伪装为正常空库。

本期不提供逐库模型配置、自动监听、上传、知识包导入导出、Agent 挂载或运行期跨进程任务重连。这里只接入独立库的显式手动维护，不改变 Agent capability 中尚未接通的 maintenance worker 协议。

## 全局模型配置

Platform 从 `configs/kbase-settings.yml` 的 `embedding.modelKey` 和模型 registry 生成私有快照 `<StateDir>/kbx/index.yml`，所有独立库共用。`embedding.prompt` 支持 `raw` 和 `qwen3`；配置变更重启 Platform 生效。生成文件不应人工维护凭据。

子进程注入 `KBX_CONFIG_FILE`，同时通过当前 CLI 支持的 `--config` 指向同一文件，并设置 `KBX_CONFIG_DIR`。当前 CLI 尚未原生识别 FILE，单独设置该变量不会生效。

未选择 embedding 时保持全文检索；选择后更新索引追加 `embed -c workspace` 并核验向量完整性，召回使用 `query --agent --full --no-graph --no-rerank`。全文更新成功但向量失败仍返回错误。更换模型后需更新索引，由 KBX 检查向量兼容性。查询扩展、重排及图谱模型尚未配置。

## HTTP 契约

接口沿用 Platform 现有 HTTP 鉴权和 `{code,msg,data}` 包裹，管理中心为部署级资源。

| 方法与路径 | 用途 |
| --- | --- |
| GET /api/admin/kbases | 定义数组 |
| POST /api/admin/kbases | `{name,description,sourcePath}` 创建 |
| GET /api/admin/kbases/{id} | 单库定义、状态与最近错误 |
| PUT /api/admin/kbases/{id} | `{name,description}` 编辑 |
| DELETE /api/admin/kbases/{id} | 删除中心副本，保留源文件 |
| POST /api/admin/kbases/{id}/refresh | 启动后台更新，返回 indexing 定义 |
| GET /api/admin/kbases/{id}/status | KBX 状态数据 |
| GET /api/admin/kbases/{id}/files | KBX 文档目录 |
| POST /api/admin/kbases/{id}/search | `{query,limit}` 全文召回，默认 10 |
| GET /api/admin/kbases/{id}/read?ref=… | 按 `kbx://workspace/...` 读取正文 |

不存在返回 404，索引期间的冲突返回 409，错误方法返回 405，参数或执行失败返回 400，中心未装配返回 503。查询和读取有 30 秒超时。

## 验证

`internal/kbasescenter` 测试覆盖持久化、删除保留源文件、并发更新拒绝、路径隔离和中断恢复；Server 测试覆盖 CRUD 与 HTTP 错误。`KBX_CENTER_TEST_BIN=<受管 bin 目录> go test ./internal/kbx -run TestCenterRealCLI -count=1` 在临时库验证首次建库、再次更新、全文召回、正文读取、文档更新与删除同步。
